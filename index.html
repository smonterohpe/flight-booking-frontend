¿Qué es Flight Booking Simulator?

Flight Booking Simulator es un simulador de reservas de vuelos en tiempo real, pensado como demo de continuidad de negocio. Genera reservas aleatorias entre clientes y vuelos mediante el Generador Aleatorio de Reservas (RBG), las almacena en base de datos y las expone a la Observability Console para su monitorización.

  • ✓ Creación manual de reservas por cliente y vuelo
  • ✓ Vistas de clientes y vuelos en tiempo real
  • ✓ Monitorización de estado desde la Observability Console (KPIs, Systems, Zerto)
