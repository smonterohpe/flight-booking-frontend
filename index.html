¿Qué es Flight Booking Simulator?

Flight Booking Simulator es un simulador de reservas de vuelos en tiempo real, pensado como demo de continuidad de negocio.

Stack tecnológico

FRONTEND
nginx HTML5 CSS3 JavaScript
BACKEND
Python 3.12 FastAPI Gunicorn SQLAlchemy
DATABASE
PostgreSQL 16
INFRAESTRUCTURA
Máquinas virtuales Linux

Funcionalidades

  • Generación automática de reservas aleatorias con ritmo configurable (RBG)
  • Creación manual de reservas por cliente y vuelo
  • Vistas de clientes y vuelos en tiempo real
  • Monitorización de estado desde la Observability Console (KPIs, Systems, Zerto)
